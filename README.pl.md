# zenonum-governance (po polsku)

Jedno publiczne repozytorium o governance zenonum: architektura, silnik startupowy, interfejs, macierz ról agentów którzy zenonum budują i agentów którzy w zenonum pracują, fragment zanonimizowanego rejestru decyzji, separacja obowiązków i wynik testów. Wersja beta działa. Następny etap — ten sam ład, doprowadzony od zaakceptowanego kontraktu do działającej linii produktu — jest opisany jako architektura dostawy, nie jako osobny produkt.

Pełny opis w języku angielskim: [README.md](README.md).
